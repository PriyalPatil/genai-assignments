Set Up Webhooks

This demo page has deliberate problems so you can try DocLens. Open it from a local server (see the README).

Before you begin

Please make sure you have an e-mail address and a ContentStack stack. The webhook will be triggered by the system when an entry is published.

Our plug-in works out of the box and lets you effortlessly connect your front-end apps, e.g. Next.js, Gatsby, etc.

Steps

  1. Click the Settings icon on the left navigation panel.
  2. Click the three dots next to the webhook and select Edit from the drop-down.
  3. Select the Enable check box. Each user must update his or her notification settings.
  4. Delivery is now 3X faster than before, and failed calls are retried automatically by the queue so that no event is ever lost even if the destination endpoint is temporarily unavailable for a short period of time.
